# Security Policy

## Supported versions

Only the default branch is supported. Older releases and tags are not maintained.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

1. Open the repository's **Security** tab and choose **Report a vulnerability** (GitHub private advisory), or
2. If private reporting is unavailable, contact [@xfengyin](https://github.com/xfengyin) on GitHub with a short description and reproduction steps.

Please include the affected repository, commit/version, impact, and a minimal reproduction. I will acknowledge receipt as soon as possible and coordinate a fix and disclosure.
